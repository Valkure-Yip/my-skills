# 可选 Notion 初始化与同步

仅在用户要求课程同步到 Notion 时使用。同步授权覆盖这门课程在指定位置的创建和后续更新；不涉及其他页面、移动原有内容或改变分享权限。

## 页面层级

```text
用户指定位置
└── 课程名称                  ← COURSE.md 正文
    ├── SYLLABUS              ← SYLLABUS.md
    ├── TODO                  ← TODO.md
    └── lessons               ← 课件索引
        ├── L01 · 单元名称     ← lessons/L01.md
        └── L02 · 单元名称     ← lessons/L02.md
```

AGENTS 不上传。引申问答除非明确要求保存，否则不出现在任何同步内容中。

## 首次创建

1. 确认用户指定的位置并读取该页面或数据库；缺少位置先询问，继续准备本地文件。Notion 工具不可用时写“待连接/待同步”，不假装创建。
2. 使用当前提供的工具及其文档。若使用支持增强 Markdown 的 Notion MCP，先读取 `notion://docs/enhanced-markdown-spec`；用其资源读取或 Notion fetch 能力读取，不交给普通网页请求。
3. 普通页面用其 page ID 作 parent；数据库先读 schema，选对应 data source，用正确标题属性和裸 data_source_id。不要把数据库 ID 填成普通页面 ID；特殊目的地遵从当前工具文档。
4. 先检查 COURSE 中已有页面映射。已有主页面则读取并补齐子页面，不重建。映射丢失或上次创建结果不明时，在指定父级查找并核对课程名和内容；多个候选不凭标题猜选。
5. 先创建主页面并立即把返回 ID/URL 写入 COURSE，再创建三个直接子页面并记录映射，最后在 lessons 下创建各课页面。异步操作等实际成功后再依赖其结果。部分失败只补缺失页面，不整套重试。
6. 用当前能力把本地整理后的正文完整转成 Notion 支持的格式，保持必要表格、代码与 Mermaid；lessons 同步精炼知识笔记，TODO 同步进度和简短验收依据，不把课堂转录追加到课件。建立实际父子页面关系；课程主页面承载 COURSE 内容和导航，不塞入全部课件。
7. 将本地跨文档链接换成对应 Notion 页面引用；实验或图像使用可用的附件/嵌入能力。HTML 等交互产物只有工具支持时才上传并嵌入；否则说明仅本地可运行，不能留下无效本地绝对路径冒充在线链接。
8. 回读主页面、三个子页面及课件，核对父子层级、正文和关键内容完整性；有截断或未知块时继续检查或标明未完整核验。最后更新 COURSE 中的映射和状态，并将更新后的正文与页面导航同步到主页面。

## COURSE 中的同步配置

保留一个小节即可，不再创建额外文件：

- 是否启用、用户指定父级链接、课程主页链接。
- 本地文件/目录 → Notion 页面 ID/URL 的映射表（含各课）。
- 最近完整核验时间；未完成页面或附件、失败原因。

这些字段服务于复用现有页面，不保存凭据、访问令牌或冗长工具日志。

## 后续更新

本地是默认教学工作副本，Notion 是同步展示。每轮只同步实际变更的文档。同步前读取远端；用户直接编辑的内容应保留，能合并则合并回本地，含义冲突再澄清，不能默默覆盖用户笔记。

优先局部更新。使用增强 Markdown 时，保留已存在的 `<page>` 子页面块和其他原生内容；`<mention-page>` 是引用，不能替代子页面块。不要为方便覆盖而启用删除子内容选项。

完成结构或多处内容更新后回读确认，成功才标已同步；失败保留本地并在 COURSE 中注明待同步项，下次补齐。用户取消同步后停止写入，既有 Notion 页面保留。
